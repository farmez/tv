# Accueil — module TizenBrew

Ecran d'accueil minimaliste style Apple TV pour Samsung Tizen.

- Grille des applications + dock de favoris (8 max)
- Horloge et date en francais
- 5 decors nature en SVG, rotation toutes les 45 s
- Navigation telecommande : fleches, OK, Retour (10009)
- Favoris persistes en localStorage

Concu pour le SoC Kant-SU2 BASIC : aucun backdrop-filter, animations
limitees a transform/opacity, decors vectoriels. 28 Ko, aucune
dependance externe.

## Installation

TizenBrew Installer -> ajouter un depot GitHub au format `utilisateur/depot`.
